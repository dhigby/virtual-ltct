# Translation Tools

**Category:** Technology Domain

## Description

Knowledge of current recommended translation tools.

## Why it matters

For many Language Technologists, the input, verification, management and publishing of translated data will be a core activity of the parent organisations. As LT responds to the needs of other domains, this is among the first competencies to study.

## Target competency

> Is able to train others in the effective use of current translation tools.

### 3.0 — Scripture Markup and Import

_Scripture translation will be a priority for most Language Technologists. Scripture is marked with tags that represent both structure and formatting. Specialists will need to know the intentions and tags of the current Scripture markup standards. Consultants may be asked to convert from older standards. Equipped with this knowledge, a Language Technologist will be able to prepare Scripture typed in other formats for importation into translation tools. They will also be able to help teams to properly work with and translate Scripture verses._

| Current level | Suggested activities | Reaches |
| --- | --- | --- |
| **0 - No Competency** | Can identify common markup notation for Scripture data based on the current standards. | 1 - Has Knowledge |
| **1 - Has Knowledge** | Can produce common markup for Scripture data based on the current standards. | 2 - With Assistance |
| **2 - With Assistance** | Convert and import data from other formats (plain text, Word document, etc.) into translation software. | 3 - Independent |
| **3 - Independent** | — | 4 - Expert |
| **4 - Expert** | Train others to convert and import Scripture data. | — |
