# Keyboard Development

**Category:** Technology Domain

## Why it matters

If keyboarding solutions are non-existent or poorly adapted to input of local languages, a Language Technologist may be needed to develop a new solution,

## Target competency

> Can develop and trains others to develop custom keyboard and data-entry tools.

## Progression by component

_Each row is a level a learner is **at**; its activities are what they do to reach the level in the final column._

### 1.0 — Typing Keyboard Development

| Current level | Suggested activities | Reaches |
| --- | --- | --- |
| **0 - No Competency** | Examine local and nearby keyboards to learn the strategies used for text input. | 1 - Has Knowledge |
| **1 - Has Knowledge** | Learn the keyboard coding environment and how to compile a typing keyboard | 2 - With Assistance |
| **2 - With Assistance** | Create and distribute a custom typing keyboard solution | 3 - Independent |
| **3 - Independent** | Work with individuals to create custom typing keyboarding solutions. Submit keyboards to appropriate repositories for web distribution. | 4 - Expert |
| **4 - Expert** | Teach a group how to create custom keyboard solutions for redistribution. Create and submit OS-native keyboards to appropriate repositories. | — |

### 2.0 — Touch Keyboard Development

| Current level | Suggested activities | Reaches |
| --- | --- | --- |
| **0 - No Competency** | Examine local and nearby keyboards to learn the strategies used for text input on mobile devices. | 1 - Has Knowledge |
| **1 - Has Knowledge** | Learn the keyboard coding environment and how to compile a touch keyboard | 2 - With Assistance |
| **2 - With Assistance** | Create and distribute a custom touch keyboard solution | 3 - Independent |
| **3 - Independent** | Work with individuals to create custom touch keyboarding solutions. Submit keyboards to appropriate repositories for web distribution. | 4 - Expert |
| **4 - Expert** | Teach a group how to create custom touch keyboard solutions for redistribution. | — |

### 3.0 — Language Model Development

| Current level | Suggested activities | Reaches |
| --- | --- | --- |
| **0 - No Competency** | Learn how to create ordered word lists with frequency counts | 1 - Has Knowledge |
| **1 - Has Knowledge** | Collect texts and use a tool to create a language model | 2 - With Assistance |
| **2 - With Assistance** | Create a predictive keyboard by adding a language model to an existing keyboard. | 3 - Independent |
| **3 - Independent** | Work with individuals to create language models for text entry. Submit language models to appropriate repositories for web distribution. | 4 - Expert |
| **4 - Expert** | Teach a group how to create language models for redistribution. Explore configuration of morphological options in language models. | — |

_Level 4 activities aim past the top of the CBC scale (the source spreadsheet's "level 5"), which CBC does not define._
