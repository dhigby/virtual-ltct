# Scripture Pre-publishing Checks

*Title in the source material: "Finalizing Your Translation for Publication."*

A multi-chapter **workbook** used during the final pre-publishing workshop (typically run over
about two weeks). Working through it, a translation team runs all the relevant final checks in
**Paratext** — most of which they have done before — to produce publication-ready USFM scripture
files for typesetting. It follows **Stage 6 ("Finalising for publication")** of the
[Paratext Training Manual](https://manual.paratext.org), and is written for **experienced
translators**.

> **Note:** this is a facilitated workshop workbook, not a self-paced Learning That Lasts course —
> so it deliberately does **not** follow the 4Cs lesson structure or the pipeline package, and it
> is not run through `check_course_package.py`.

> **For consultants:** this workbook is written for the translation team doing the work. The
> consultant-facing course that prepares you to *support* a team through these checks is
> [Supporting Scripture Pre-publishing Checks](../supporting-pre-publishing-checks/README.md).

## Chapters

1. [Adding Illustrations](01-adding-illustrations.md)
2. [Preparing the Front/Back Matter](02-preparing-the-front-back-matter.md)
3. [Compare Parallel Passages](03-parallel-passages.md)
4. [Proper Names and Biblical Terms](04-proper-names-and-biblical-terms.md)
5. [Numbers, Weights, and Measures](05-numbers-weights-and-measures.md)
6. [Formatting Checks](06-complete-comprehensive-formatting-checks.md)
7. [Glossary Linking: Marking Terms in the Text](07-glossary-linking-marking-terms-in-text.md)

The **FC (Formatting Checks)** referenced in Chapter 6 is an *earlier* check in the manual
([13. Formatting checks](https://manual.paratext.org/13.FC)) that the team **reruns** here to catch
any errors introduced since.
