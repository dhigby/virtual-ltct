# Lexical Import

**Category:** Technology Domain

## Why it matters

Lexicons are, by nature, structured documents. various standards have been proposed, used, and abandoned over the years. This specialist competency involves disambiguation (removing any doubt about the classification and relationship) of data and importation into a modern lexicography program. This is often a non-trivial task when importing poorly structured or unstructured data. Once the data is clean, structured, and in an appropriate encoding, it can then be imported into a modern lexicography tool.

## Target competency

> Can disambiguate and import language data into current lexical software

## Progression by component

_Each row is a level a learner is **at**; its activities are what they do to reach the level in the final column._

### 1.0 — General

| Current level | Suggested activities | Reaches |
| --- | --- | --- |
| **0 - No Competency** | Identify legacy markup commonly used in language data for your entity (SFM, MDF, LIFT, etc.) | 1 - Has Knowledge |
| **1 - Has Knowledge** | Understand how to restructure lexical data to make it unambigious and learn to use relevant import/conversion tools | 2 - With Assistance |
| **2 - With Assistance** | Use automated processes to restructure and disambiguate lexical data and import into a current lexical database | 3 - Independent |
| **3 - Independent** | Teach others to disambiguate and import lexical data into structured lexical tools. | 4 - Expert |
| **4 - Expert** | Convert unformatted dictionaries (e.g., Word, PDF) into a structure format and import them into the recommended tool. | — |

_Level 4 activities aim past the top of the CBC scale (the source spreadsheet's "level 5"), which CBC does not define._
