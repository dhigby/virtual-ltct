# **Consultant’s Triage Guide **

**"Consultant's Triage Card"** you must fill out for each scenario.

> **Scenario ID:** ________
>
> 1. **Data Status:** Is the data backed up? (Yes/No/Unknown)
> 2. **Safety Risk:** Is there smoke, smell, or swelling? (Yes/No)
> 3. **The "Golden Test":** What one test isolates the problem fastest? (e.g., External Monitor, Disable Touchpad, Plugged-in vs Battery)
> 4. **The Workaround:** If a part takes 2 months to arrive, how does the user work tomorrow?
